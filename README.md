# Калькулятор проектировщика

Десктопное (веб) приложение на **Flutter** для строительных организаций. По шагам помогает спроектировать один из видов конструкции:

- многоквартирный дом *(в разработке)*;
- частный дом — реализован визард выбора фундамента;
- металлические конструкции *(в разработке)*.

Приложение поддерживает **два режима работы** (клиент / проектировщик), сохраняет проекты локально и позволяет вернуться к каждому проекту в любой момент.

## Что уже умеет приложение

1. **Выбор режима** при первом запуске — клиент или проектировщик. Меняется в настройках.
2. **Список проектов** на главной: каждый проект — это «папка» с названием, типом конструкции и датой обновления. Поддерживаются переименование и удаление.
3. **Создание проекта**: задаём название и тип конструкции — частный дом, многоквартирный дом, коммерческое здание, коммерческое сооружение, металлические конструкции (пока активен только частный дом, остальные со статусом «скоро»).
4. **Внутри проекта** — три раздела верхнего уровня:
   - Бриф клиента *(заглушка, будет визард)*;
   - Состав сооружения *(папка с конструктивными элементами: фундамент, стены, крыша, лестница)*;
   - Чертежи *(пока пусто, появятся после автогенерации)*.
5. **Визард фундамента**:
   - 5 типов: свайный, плитный, ленточный, столбчатый, сваи с ростверком;
   - устройство: винтовые / буронабивные / монолитный / сборный (зависит от типа);
   - для свай с ростверком — материал ростверка (монолитный / сборный).
6. **Локальное сохранение** через `shared_preferences` (на вебе — `localStorage`, на десктопе — файл, на мобильных — нативные настройки).

```

├── models/                          доменная модель проекта
│   ├── construction_type.dart        тип конструкции (частный дом / много­квартирный / металл)

│   ├── client_brief.dart             пожелания клиента
│   ├── foundation.dart               перечисления типов и устройств фундамента

│   ├── project_repository.dart       загрузка/сохранение списка проектов в JSON

    ├── project_create_page.dart      форма создания нового проекта
    ├── project_details_page.dart     экран проекта: бриф / фундамент / стены / крыша
    ├── brief_page.dart               заглушка брифа клиента
    ├── walls_page.dart               заглушка раздела «Стены»
    ├── roof_page.dart                заглушка раздела «Крыша»

    ├── metal_construction_page.dart  заглушка металлических конструкций
```

## Как запустить у себя

1. Установить Flutter SDK: <https://docs.flutter.dev/get-started/install>.
2. В корне проекта поставить зависимости:
   ```bash
   flutter pub get
   ```
3. Запустить приложение:
   ```bash
   flutter run -d chrome     # в браузере (рекомендуем для текущего этапа)
   flutter run -d linux      # на Linux-десктопе
   flutter run -d windows    # на Windows-десктопе
   ```

## Архитектурные решения

- **Единая модель проекта (`HouseProject`)**: все данные (бриф, фундамент, стены, крыша) живут в одном объекте. Это «единый источник правды» — расчёты и чертежи будут строиться именно из него.
- **Отделение данных от UI**: `models/` — чистые классы без виджетов, `pages/` — экраны без бизнес-логики, между ними — `state/AppState` (ChangeNotifier) и `storage/` (репозитории).
- **Режим (клиент / проектировщик)** влияет на подачу интерфейса и на состав выходных документов. Сейчас разница ещё не сильная, но архитектура уже готова к разделению.
- **Хранение** — локальное (`shared_preferences`). При необходимости заменим на облако, не меняя UI: достаточно подменить реализации `ProjectRepository` и `SettingsRepository`.
